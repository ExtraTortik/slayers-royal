# Инструкция по развёртыванию проекта на новом компьютере

Привет! Этот пакет содержит полный инструментарий ромхакинга, реверс-инжиниринга и локализации игры **Slayers Royal (Sony PlayStation 1)**, а также готовые скрипты сборки, отладки в эмуляторе и конфигурации ИИ-агентов.

---

## Быстрый старт в один клик

### На Windows:
1. Установите Python 3.10+ с [python.org](https://www.python.org/) (галочка `Add Python to PATH`). Git не обязателен.
2. Положите свой дамп диска в `downloads\sr.bin` (Redump, SLPS-01363):
   * размер: `712 300 848` байт
   * SHA-256: `89760d728f0580dba1c6176f024d3cd6f8fc105b79bd1c27a819208fa0b4d0fe`
   * `downloads\sr.cue` создастся автоматически.
3. Запустите двойным кликом:
   ```cmd
   start_project.bat
   ```
   Скрипт поставит Python-зависимости, скачает upstream-тулкит `patch_repo/`
   (~120 МиБ, точный commit), проверит образ и откроет меню.
4. Для запуска нужен эмулятор PS1: установите [DuckStation](https://www.duckstation.org/)
   или распакуйте portable-сборку в `tools\bin\duckstation\`.
   Затем: `run_game.bat` (при необходимости сам соберёт русский образ).

Сборка без меню: `build.bat` (полная) или `build.bat --story` (быстрая).
Запуск: `Запустить_Игру_PS1.bat`.

### На Linux / macOS / WSL:
1. Откройте терминал в папке проекта.
2. Сделайте скрипт исполняемым и запустите:
   ```bash
   chmod +x start_project.sh
   ./start_project.sh
   ```

## Структура переданного пакета

* **`build.sh` / `build.bat`** — модульный сборочный компилятор диска (собирает русский `.bin`/`.cue` за ~12–38 сек).
* **`run_game.sh` / `run_game.bat`** — автолаунчер эмулятора (автоматически находит DuckStation / Mednafen и передаёт диск).
* **`start_project.sh` / `start_project.bat`** — мастер-скрипт входа и проверки системы.
* **`EMULATOR_DEBUGGING_GUIDE.md`** — детальное руководство по отладке через DuckStation (VRAM-дампы, патчинг RAM в сейвстейтах, аппаратные MIPS-брейкпоинты).
* **`PS1_ROMHACKING_GUIDE_WINDOWS.md`** — инженерное руководство по форматам PS1 (CD-ROM XA Mode 2 Form 1, расчёт EDC/ECC, TIM, шрифты).
* **`hand_off.md`** — единый мастер-документ состояния проекта со всеми адресами памяти и статусом 562 тестов.
* **`translations/`** — все 10 мастер-каталогов в формате JSON (сюжетные диалоги, боевой режим, 149 комнат, мини-игры, карты, плашки, службы).
* **`tools/`** — 40+ утилит ромхакинга и 28 тестовых наборов `test_*.py`.
* **`agent_config/`** — шаблоны настроек и спецификации 5 ролей агентов (Orchestrator, Scout, Task, Reviewer, Security).

## Настройка ИИ-агентов (если продолжаете работу с LLM)

Если вы работаете в агентской среде (Oh My Pi, OpenDevin, Cursor, Claude Desktop):
1. Откройте папку `agent_config/`.
2. В файле `models.yml.template` впишите ваши API-ключи провайдеров.
3. Скопируйте шаблоны в рабочую папку харнеса:
   * Windows: `%USERPROFILE%\.omp\agent\`
   * Linux: `~/.omp/agent/`
4. Подробная спецификация ролей и промптов описана в `agent_config/AGENT_ROLES.md`.
