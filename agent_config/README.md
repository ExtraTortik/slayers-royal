# Конфигурация агентов и архитектура оркестрации

> **Назначение:** Полный набор спецификаций, промптов и конфигураций субагентов для переноса и запуска проекта на другой рабочей станции в любой агентской среде (Oh My Pi, OpenDevin, Cursor, Claude Desktop, Aider).

---

## 1. Ролевая модель агентов (Agent Taxonomy)

Проект использует строгое разделение труда на 5 специализированных ролей:

### 1. `Main` / `Orchestrator` (Оркестратор)
* **Роль:** Главный планировщик и координатор сессии.
* **Правило:** Никогда не делает всё в одиночку последовательно, если задачи можно распараллелить. Декомпозирует цель на независимые ветви (Reverse Engineering, Ассеты, Скрипты, Тесты) и запускает субагентов через `task`.

### 2. `scout` (Быстрый исследователь-разведчик, READ-ONLY)
* **Роль:** Эксплораторное исследование кодовой базы, поиск структур данных, дизассемблирование, картографирование файлов.
* **Модель:** Быстрая и лёгкая модель с широким контекстом (например, `gemini-3.8-flash`, `deepseek-v4.1-flash`, `gpt-4o-mini`).
* **Ограничение:** Не делает правок кода. Возвращает сжатый отчёт с точными смещениями, адресами и сигнатурами для последующих исполнителей.

### 3. `task` (Инженер-исполнитель)
* **Роль:** Делегированные многошаговые задачи полного цикла (написание скриптов, извлечение спрайтов, конвертация, интеграция в код).
* **Модель:** Полнофункциональная модель рассуждений (например, `gemini-3.8-flash:high`, `gpt-5.2`, `claude-3-7-sonnet`).

### 4. `reviewer` (Ревьюер качества и регрессий)
* **Роль:** Анализ написанного кода перед коммитом на чистоту, соответствие архитектуре, отсутствие регрессий и переполнения секторов.

### 5. `security-reviewer` (Безопасность и целостность)
* **Роль:** Проверка инвариантов памяти (защита от переполнения буфера RAM, проверка контрольных сумм EDC/ECC, корректность указателей).

## 2. Шаблоны конфигурационных файлов

В этой папке подготовлены готовые шаблоны для развёртывания окружения:

1. **`config.yml.template`** — глобальные настройки агентского харнеса:
   * Настройка символов UTF-8.
   * Назначение роли `default` на основную модель.
   * Уровни автоматического мышления (`defaultThinkingLevel: auto`).
2. **`models.yml.template`** — реестр провайдеров и моделей:
   * Настройка эндпоинтов (OpenAI, Anthropic, OpenRouter, Google, локальный vLLM/Ollama).
   * Описание контекстных окон (128k..400k) и лимитов токенов.
3. **`mcp.json.template`** — конфигурация серверов Model Context Protocol (MCP):
   * `codebase-memory-mcp` — граф знаний и индексация проекта.

## 3. Как развернуть на новой машине

1. Скопируйте шаблоны в рабочую папку конфигурации вашего харнеса (например, `~/.omp/agent/` для Oh My Pi или в конфигурационную папку вашей среды):
   ```bash
   mkdir -p ~/.omp/agent
   cp agent_config/config.yml.template ~/.omp/agent/config.yml
   cp agent_config/mcp.json.template ~/.omp/agent/mcp.json
   ```
2. В файле `models.yml` укажите ваши API-ключи:
   ```yaml
   providers:
     main-provider:
       baseUrl: https://api.openai.com/v1
       apiKey: "ваш-api-ключ"
   ```
3. Запустите мастер-скрипт проекта:
   ```bash
   ./start_project.sh
   ```
   (или `start_project.bat` на Windows).
