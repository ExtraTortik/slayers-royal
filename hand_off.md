## 2. Архитектура игры и реверс-инжиниринг

### 2.1. Структура диска и LBA-сектора
* **LBA 16 (0x10):** Primary Volume Descriptor (PVD).
* **LBA 22:** Корневой каталог ISO-9660.
* **LBA 24:** Исполняемый файл `SLPS_013.63` (210 944 байт, 103 сектора).
* **LBA 127:** Видеоролики FMV `MOVIE.STR` (строго **184 290 секторов**, 377 425 920 байт).
* **LBA 223787:** Мини-игры `SMINI.UNT` (4 532 224 байта, 181 запись).
* **LBA 226000:** Опции и системные ресурсы `OPT.UNT` (6 184 960 байт, 233 записи).
* **LBA 229020:** Основной программный контейнер `PROG.UNT` (8 822 784 байта, 444 записи).
* **LBA 233328:** Графика локаций и фоны `BASYOG.UNT` (14 254 080 байт, 480 записей).
* **LBA 240288:** Звуковые треки CD-XA `SLAY.XAB` (49 741 824 байта).
* **LBA 264576:** Кинематографический плеер `OPTCINE.GRP` (105 536 байт).

### 2.2. Сюжетные диалоги (`PROG.UNT 0x03B..0x057`)
* **Каталог перевода:** `patch_repo/localization-work/ru/dialogue.po`.
* **Объем:** **4 514 записей из 4 514 переведены на 100% (0 непереведённых)**.
* **Валидация:** Каталог успешно проходит строгую валидацию `localize.py validate` **без флага `--allow-incomplete`**.
* **Устранение «каракулей» (модзибаке):**
  * В оригинальном движке при пустой строке `msgstr ""` игра брала японские байты с диска. Так как в VRAM японские глифы заменены русскими, непереведённые развилки (например, выбор в таверне `0x03B/E01B/061` `詳しく聞いてみる。/ 聞くのをやめる。`) выводились в виде смеси кандзи и русских букв (`詳「ё 聞 〕 к ц я 。`).
  * Все 103 развилки и выбора по всей игре переведены на чистый русский язык (выбор в таверне: *«Расспросить. / Хватит.»*). Каракули устранены на 100%.
* **Устранение пустых окон диалога (MAIN ST и далее):**
  * В сцене `0x03C` (Главная улица Лейквуда) 189 реплик жителей и спутников были пропущены в английском фанатском моде. Все 189 реплик переведены, пустые окна ликвидированы.
* **Секторный бюджет PROG.UNT:**
  * Донорский блок `0x011` содержит 164 свободных нулевых сектора (337 КБ).
  * Из него выделено 49 секторов для 19 расширенных сцен (включая `0x03B` +4 сектора, `0x03E` +13 секторов, `0x040` +5 секторов), что позволило разместить весь русский текст без обрезки предложений.
* **Шрифт диалогов:**
  * Установлен аутентичный 8-битный ретро-шрифт **Press Start 2P** (`fonts/PressStart2P.ttf`).
  * Кегль **11 pt**, базовая линия $y = 12$, горизонтальное центрирование. Строго $\le 15$ символов на строку.

### 2.3. Осмотр предметов в комнатах (`PROG.UNT 0x059..0x0F8`)
* **Мастер-каталог:** `translations/room_inspection_ru.json` — **понятный человеку JSON-файл для удобного ручного контроля и редактирования**.
* **Объем:** Все **149 интерактивных комнат** игры, **734 уникальные строки** (2 936 вхождений).
* **Восстановление 37 комнат из японского оригинала:**
  * Автор английского патча вырезал (заполнил нулями) описания в 37 комнатах игры, включая **MAIN ST (`0x059`)**.
  * Мы декодировали японский оригинал из `downloads/sr.bin` через `CHARMAP`, перевели все 43 строки улицы MAIN ST от лица Лины Инверс (*«Небо между деревьями»*, *«Колодец на площади»*, *«Обычный старик»*, *«Да земля же, говорю тебе!»*) и встроили в игру.
* **Устранение обрывов предложений («что...»):**
  * Все 143 фразы, которые ранее механически урезались на 15 символах, перефразированы в законченные, остроумные предложения (например: *«Вон то окно / открыто. Кинуть / туда камешек?»* вместо *«Окно открыто... камешек, что...»*).
* **Пакетный инжектор:** `tools/patch_inspection.py` с автоматическим пересчётом 32-битных указателей памяти (база `0x00200000`) и защитой от переполнения секторов.

### 2.4. Энциклопедические карточки персонажей (Lore Cards)
* **Каталог:** `data/lore_cards_ru.json` (все 13 справочных карточек и 11 заголовков).
* **Формат:** Полноэкранные текстуры оверлея формата **4bpp TIM** ($320 \times 224$ пикселя), сжатые алгоритмом `unt_lz` mode 1 в `PROG.UNT` (записи 32, 34, 36, 38, 40, 41, 43, 45, 47, 49, 51, 53).
* **Шрифт карточек:** **Liberation Sans** (Bold для заголовков, Regular с тенью для описаний). Пропорциональный шрифт гарантирует отступ не менее 39 пикселей от правого края и исключает вылезание текста за границы экрана.
* **Инжектор:** `tools/patch_lore_cards.py`.

---

### 2.5. Видеоролики FMV (`MOVIE.STR`)
* **Расположение:** LBA 127..184416 (184 290 секторов, 433 МБ).
* **Количество:** 12 роликов (`s00`..`s11`).
* **Озвучка и субтитры:**
  * Видеоролики содержат японскую речь.
  * Все 11 сюжетных роликов (`s01`..`s11`) захардсаблены русскими субтитрами из `renpy_extracted/game/videos/s01_ru.srt`..`s11_ru.srt`.
* **Устранение чёрного экрана (Seek Error fix):**
  * В `tools/bin/psxavenc` добавлен параметр `-L <starting_lba>`, благодаря чему каждый сектор ролика получает точный физический аппаратный заголовок **BCD MSF** (+150 pregap), совпадающий с положением дорожки (сектор 0 ролика 1 имеет строго `03:03:53`).
  * Флаг `-X` задаёт точное чередование секторов: **31 сектор видео $\to$ 1 сектор аудио (Interleave 1/32)**, что предотвращает опустошение буфера MDEC.
* **Инжектор:** `tools/fmv_pipeline.py`.

## 4. Памятка по командам управления

### Запуск игры в эмуляторе:
```bash
./run_game.sh              # Запуск русской версии
./run_game.sh --orig       # Запуск японского оригинала
./run_game.sh --dry-run    # Проверка файлов без открытия GUI
```

### Пересборка локализации:
```bash
./build.sh --quick         # Быстрое обновление (только если правили translations/room_inspection_ru.json, ~2 сек)
./build.sh                 # Полная сборка (если правили dialogue.po или карточки, ~20 сек)
./build.sh --validate      # Проверка всех текстов на соблюдение лимитов PS1 (15 символов)
```

### Запуск тестов:
```bash
python3 -m pytest tools/ -q                                                              # 58 тестов тулчейна
cd patch_repo && SLAYERS_ROYAL_BIN="$(realpath ../downloads/sr.bin)" pytest localization/tests -q  # 10 тестов интеграции
```
*(Всего 68 тестов — все проходят со 100% успехом).*
